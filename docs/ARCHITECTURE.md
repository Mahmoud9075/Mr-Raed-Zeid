# المعمارية

## الاختيار التقني
- **Frontend:** Next.js + React + TypeScript. اخترناه بدل React/Vite وحده لأن موقع مدرس عام يحتاج SEO وMeta Tags وصفحات عامة سريعة، مع الحفاظ على تجربة React للبوابة والاختبارات.
- **Backend:** FastAPI + SQLAlchemy. سريع، واضح، ويعطي API موثقة تلقائيًا، ومناسب لبناء لوحة الأدمن والاختبارات.
- **Database:** PostgreSQL في الإنتاج، وSQLite للتطوير المحلي السريع.
- **Reverse Proxy:** Caddy أمام الـFrontend والـAPI.

## التدفق
Browser → Caddy → Next.js للصفحات / FastAPI لمسارات `/api/*` → PostgreSQL.
