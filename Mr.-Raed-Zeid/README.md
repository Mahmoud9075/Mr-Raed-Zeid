# Mr. Raed Zeid — Full‑Stack Learning Platform v2

مشروع كامل Frontend + Backend + Database مبني بـ **Next.js/React/TypeScript + FastAPI + PostgreSQL + Docker** وبنفس الهوية الكحلي/الذهبي لموقع مستر رائد.

## التشغيل الأسرع
### Windows
1. فك الضغط.
2. شغّل Docker Desktop.
3. افتح `START_WINDOWS.bat`.
4. افتح `http://localhost`.

### Linux / macOS
```bash
./START_LINUX_MAC.sh
```

أول تشغيل ينسخ `.env.example` إلى `.env`. بيانات Owner المحلية موجودة داخل `.env`. **غيّر كلمة المرور وJWT وPassword قاعدة البيانات قبل رفع الموقع على الإنترنت. لا ترفع `.env` على GitHub.**

## الموجود فعليًا
- Landing page Responsive بنفس الهوية الأصلية والصور والفيديوهات.
- حسابات طلاب حقيقية محفوظة في PostgreSQL.
- تسجيل متدرج: **مرحلة → نوع تعليم → صف/فرقة**.
- الابتدائي موجود في النظام لكنه غير مفعّل للتسجيل افتراضيًا، ويمكن تفعيله من لوحة الإدارة.
- صفحة حساب الطالب: صورة شخصية، بياناته، المرحلة، نوع التعليم، الصف، المدرسة/الكلية.
- لوحة طالب ذكية: نتائج، متوسط تقدم، إشعارات، اختبارات، بحث، ومساعد.
- بحث داخل المنصة.
- إشعارات حسب المرحلة/نوع التعليم/الصف.
- اختبار تحديد مستوى 50 سؤالًا + حفظ المحاولات والنتائج.
- إنشاء اختبارات من لوحة الإدارة حسب **المرحلة → النوع → الصف**.
- أنواع أسئلة: اختيار من متعدد، صح/خطأ، إجابة قصيرة، مقالي.
- تصحيح تلقائي للأسئلة الموضوعية والإجابة القصيرة، والمقالي يعلَّم كمحتاج مراجعة.
- حد لعدد المحاولات + وقت الاختبار + نشر/إلغاء نشر + أرشفة بدل الحذف المباشر.
- تقييمات الطلاب تبدأ من صفر ولا تُنشر إلا بعد موافقة الإدارة.
- لوحة Admin مخفية من القوائم العامة.
- Owner + عدة Admins عن طريق دعوات منفصلة.
- صلاحيات Owner لإدارة الأدمنز.
- وضع صيانة للموقع من لوحة الإدارة.
- إدارة صفحات: إظهار/إخفاء، إنشاء صفحة جديدة، وأرشفة الصفحات غير الأساسية.
- تأكيد قبل العمليات الحساسة في واجهة الإدارة.
- Audit Log في قاعدة البيانات.
- رفع صورة الطالب إلى Storage محلي دائم داخل Docker volume.
- قاعدة معرفة لمساعد مستر رائد بالمواعيد والأسعار والحجز والمراحل والمعلومات المعتمدة.
- المساعد يمنع الأسئلة خارج نطاق التعليم/الإنجليزي/بيانات المستر.
- المساعد يقدر يعرض آخر نتيجة للطالب من حسابه.
- تكامل Gemini جاهز: ضع `GEMINI_API_KEY` في `.env` لتفعيل الإجابات التعليمية غير المحفوظة.
- OTP لإدارة الموقع جاهز: ضع بيانات SMTP واضبط `ADMIN_OTP_REQUIRED=true`.
- Rate limiting، قفل محاولات الدخول، scrypt password hashing، JWT/refresh tokens، HttpOnly cookies، CORS، Security Headers، CSP، وAudit Log.
- Docker Compose يشغل Frontend + Backend + PostgreSQL + Caddy.

## Gemini
لا تضع المفتاح في Frontend. ضعه فقط في `.env`:
```env
GEMINI_API_KEY=...
```

## Gmail OTP للأدمن
بعد تجهيز SMTP/Gmail App Password في `.env`:
```env
ADMIN_OTP_REQUIRED=true
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USERNAME=your-admin-email
SMTP_PASSWORD=your-app-password
SMTP_FROM=your-admin-email
```
لا ترفع App Password على GitHub.
