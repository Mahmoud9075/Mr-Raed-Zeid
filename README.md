# تشغيل النسخة المحلية المضمونة على ويندوز

لتجنب فتح نسخة قديمة تعمل على Port 3000، هذه النسخة تستخدم **3100 للواجهة** و **8100 للـBackend**. شغّل فقط `START_LOCAL_WINDOWS.bat` ثم افتح `http://127.0.0.1:3100`. ملف التشغيل يمسح كاش Next القديم ويتأكد أن النسخة الجديدة نفسها هي التي تعمل قبل فتح المتصفح.

# Mr. Raed Zeid — Full‑Stack Website

مشروع موقع مستر رائد كامل: **Next.js / React / TypeScript + FastAPI + PostgreSQL + Docker** بهوية كحلي/ذهبي، وواجهة Responsive للموبايل والتابلت واللاب.

## التشغيل الأسرع
### Windows
1. فك الضغط.
2. انسخ `.env.example` إلى `.env` واضبط كلمات المرور والأسرار ومفتاح Gemini إن أردت تشغيل المساعد الذكي.
3. شغّل Docker Desktop.
4. افتح `START_WINDOWS.bat`.
5. افتح `http://localhost`.

### تشغيل محلي على Windows بدون Docker
لو Docker غير متاح، وبعد تثبيت متطلبات Python و`frontend/node_modules`، شغّل `START_LOCAL_WINDOWS.bat`. هذا يشغّل Backend على `127.0.0.1:8000` وFrontend على `localhost:3000` بنفس قاعدة SQLite الثابتة داخل `backend/raed.db`.

### Linux / macOS
```bash
./START_LINUX_MAC.sh
```

ملف التشغيل لا ينشئ `.env` تلقائيًا لأسباب أمنية. أنشئه أنت من `.env.example`، واستخدم أسرارًا قوية وفريدة، ولا ترفع `.env` إلى GitHub أو ترسله ضمن نسخة التسليم.

- الابتدائي غير معروض للتسجيل، ولا توجد مرحلة جامعية عامة في التسجيل الحالي.
- لوحة الطالب: البيانات، الصورة، النتائج، التقدم، الإشعارات، الاختبارات، البحث والمساعد.
- اختبار تحديد مستوى إنجليزي **50 سؤالًا**، سؤال واحد كل مرة، Progress، السابق/التالي، Timer، ونتيجة فورية.
- حد للمحاولات ووقت للاختبار ونشر/إلغاء نشر وأرشفة.
- أنواع أسئلة: اختيار من متعدد، صح/خطأ، إجابة قصيرة، ومقالي.
- التقييمات تبدأ فارغة، وأي تقييم جديد يظل Pending حتى موافقة الإدارة.
- قسم «تكريمات نعتز بها» منفصل عن «طلابنا» وبفريم ذهبي ثابت مع لمعة خفيفة.
- لوحة الإدارة منفصلة عن واجهة الموقع العامة، ولا يظهر لها زر في الهيدر أو الفوتر. الدخول المباشر من `/admin/login` واللوحة من `/admin`.
- صفحات الإدارة لا تعرض الشات العائم أو هيدر الموقع العام، ومحميّة أيضًا على مستوى Backend بصلاحيات Admin/Owner.
- لوحة الإدارة تشمل إدارة الصفحات والاختبارات والحسابات والتقييمات والإعدادات وقاعدة معرفة المساعد، بالإضافة إلى النتائج والتقارير، Excel، شاشة طباعة/PDF، التصحيح اليدوي للمقالي، حالات رسائل التواصل، وسجل النشاط للمالك.
- أزرار تشغيل/إيقاف المراحل في Admin مرتبطة بالتسجيل الفعلي.
- بيانات التواصل والمواعيد والعنوان تُقرأ من إعدادات الموقع بدل الاعتماد على نص ثابت فقط.
- مساعد مستر رائد يعمل من قاعدة المعرفة، ويمكن ربط Gemini من الـBackend فقط.
- حماية: scrypt، JWT/refresh، HttpOnly cookies، CORS، Security Headers، CSP، Rate limiting وAudit Log.
- Docker Compose يشغّل Frontend + Backend + PostgreSQL + Caddy.

راجع `DEPLOY_UPDATE.md` للتفاصيل.
